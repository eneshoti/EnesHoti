Romantic story settings:
- Edit STORY_CONFIG in index.html to change the local-time opening, countdown lead, or anniversary start.
- For a temporary local test target, add ?storyTestTime=HH:MM or ?storyTestTime=HH:MM:SS to the page URL. The test value overrides only the opening time; remove it to restore the configured target.
- The personal letter is in the #letterCopy element in index.html.
- The local song is loaded from "Emina, Ti Je A Ndjenj.mp3.mpeg" in the project root. Keep the file beside index.html.
- The first-month surprise uses p1.jpeg, p2.jpeg, and p3.jpeg from the project root. Keep these files beside index.html.
